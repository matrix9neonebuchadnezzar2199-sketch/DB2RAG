## 2. 全体遷移

```
S1 RAG一覧
  └─ [新規・追加]
       ↓
S2 統合ウィザード
  ├─ 新規RAG ─┬─ MySQL ─→ 接続 ─→ DB対象 ─┐
  │           └─ ファイル ─→ 投入 ─→ 設定 ─┤
  └─ 既存追加 ─┬─ MySQL ─→ 接続 ─→ DB対象 ─┤
               └─ ファイル ─→ 投入 ─→ 設定 ─┘
                                                ↓
S3 ジョブ一覧（詳細ホバーで進捗・エラー） → S5 検索プレビュー
```

RAG一覧から既存RAGの「追加」を選んだ場合、S2のW1を `既存RAGに追加` と対象RAGが選択された状態で開く。

## 3. S2 統合ウィザード

### 3.1 工程

| 工程 | 名称 | 新規RAG | 既存RAGへ追加 |
|---|---|---|---|
| W1 | 作成先 | 新しいRAG名、既定ACL | 追加先RAGを選択 |
| W2 | 追加する方式 | MySQL / ファイル | MySQL / ファイル |
| W3 | 入力元 | MySQL接続またはファイル投入 | 同左 |
| W4 | 取り込み対象 | DBオブジェクトまたはファイル設定 | 同左 |
| W5 | 確認・変換開始 | 容量・設定の最終確認 | 同左 |

### 3.2 折りたたみ挙動

1. 初期表示ではW1だけを展開し、W2〜W5はロックした要約帯にする。
2. 選択または「確定」で現在工程を完了すると、その工程を要約帯へ畳む。
3. 同時に次工程のロックを解除し、パネルを展開する。
4. 展開中の工程は常に1つだけとする。
5. 完了済み帯の右端に `▼` を表示する。押すと工程を再展開できる。
6. 完了済み工程の値を変更した場合、その後の工程を `再確認が必要` に戻す。
7. 各工程の「戻る」は前工程を展開する。ブラウザの別ページへは遷移しない。
8. W5の「変換ジョブを作成」でのみS3へ遷移する。

### 3.3 要約帯

| 工程 | 畳んだ帯に表示する値 |
|---|---|
| W1 | `新規作成: 社内ナレッジ 2026` または `既存へ追加: 人事規程KB` |
| W2 | `MySQL 業務データベース` または `ファイル / フォルダ` |
| W3 | `host:port / database · 接続成功` または `3ファイル · 7.5 MB` |
| W4 | `2オブジェクト · 1,598 records` または `3ファイル · ACL private` |
| W5 | `容量確認済み · 変換開始可能` |

### 3.4 W1 Wireframe

```
┌ W1 作成先 ─────────────────────────── 未確定 [▲] ┐
│  [● 新規RAGを作成]  [○ 既存RAGに追加]           │
│  新しいRAG名 [社内ナレッジ 2026____________]    │
│  既定ACL      [internal ▼]                       │
│                           [この作成先で進む]      │
└─────────────────────────────────────────────────┘
┌ W2 追加する方式 ─ 前の項目を確定してください [▼]┐
└─────────────────────────────────────────────────┘
```

W1確定後:

```
┌ ✓ 作成先 ─── 新規作成: 社内ナレッジ 2026 [▼] ┐
└───────────────────────────────────────────────┘
┌ W2 追加する方式 ──────────────────────── [▲] ┐
│  [MySQLから追加]       [ファイルを投入]        │
└───────────────────────────────────────────────┘
```

### 3.5 MySQL分岐

```
W2: MySQL
  ↓
W3: ホスト / ポート / ユーザ / password / DB / SSL
    接続診断: version / TLS / charset / READ ONLY
  ↓
W4: テーブル / ビュー / 保存SQL
    PK・行数・updated_at・ACL・論理文書テンプレート
  ↓
W5: source object数 / record数 / chunk数 / 容量
```

### 3.6 ファイル分岐

```
W2: ファイル / フォルダ
  ↓
W3: D&D / ファイル選択 / フォルダ選択
    snapshot / SHA-256 / MIME / parser可否
  ↓
W4: ACL / 再帰 / 低品質PDF OCR / 拒否形式
  ↓
W5: file数 / 抽出量 / chunk数 / 容量
```
